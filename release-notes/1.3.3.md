RefPad 1.3.3 for Android

- New Settings screen (⋮ → Settings): updates, board background, memory mode, practice history, privacy.
- Shorter ⋮ menus with the main actions first; menus no longer hide behind the navigation bar.
- When a new version is out, ⋮ gets a yellow dot and Settings shows "Update to …" (plus the update pop-up).
- Practice: long-press a pose → Add this pose to the board.
- PDF reader: long-press a page → add it to the board or practise from it, right at the top.

Your board and settings are kept when you update.
